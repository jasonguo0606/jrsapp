# JRS 篮球直播

一款基于 [m.jrskk.com](https://m.jrskk.com) 的 Android 篮球直播客户端，以原生界面展示 NBA / CBA 赛事列表并在线观看直播。

---

## 主要功能

- **赛事列表**：自动获取当日 NBA、CBA 等篮球比赛，显示主客队名称、队徽、比赛时间及实时比分
- **联赛筛选**：顶部 Tab 一键切换「全部篮球 / NBA / CBA」
- **多线路直播**：每场比赛提供多条直播线路，可自由切换
- **实时比分标识**：正在进行的比赛显示「直播中」红色标签
- **一键刷新**：手动刷新赛事列表获取最新数据

## 安装

1. 在 [Releases](https://github.com/jasonguo0606/jrsapp/releases) 页面下载最新 APK
2. 在 Android 设备上允许「安装未知来源应用」
3. 安装并运行

**系统要求**：Android 8.0（API 26）及以上
